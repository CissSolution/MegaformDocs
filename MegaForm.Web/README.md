# MegaForm.Web

ASP.NET Core web host implementation for MegaForm. Provides the database layer, REST controllers, admin/dashboard UI shell, and public form rendering used by `MegaForm.AspNetCore.Component`.

This package is normally referenced transitively by `MegaForm.AspNetCore.Component`. Use that package for new ASP.NET Core hosts unless you are building a custom MegaForm host.
