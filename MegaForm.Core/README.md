# MegaForm.Core

Platform-agnostic form builder engine for DNN, Oqtane, Umbraco, nopCommerce, and standalone .NET hosts.

This package contains the core domain models, schema engine, submission pipeline, validation, workflow, and AI knowledge base logic. It is referenced automatically by `MegaForm.Sdk` and `MegaForm.AspNetCore.Component`.

Most application developers should consume `MegaForm.Sdk` or `MegaForm.AspNetCore.Component` instead of referencing this package directly.
