## AI Design Contract

Every template has `settings.aiDesignContractSlug` pointing to a per-template KB row:

- `template-guide-insurance-enrollment`
- `template-guide-event-registration-premium`
- `template-guide-elderly-care-donation`
- `template-guide-professional-application`
- `template-guide-healthcare-intake`
- `template-guide-travel-consultation`
- `template-guide-creative-workshop`
- `template-guide-volunteer-profile`

The KB files explicitly lock custom HTML, CSS selectors, dimensions, colors, borders, shadows, image URLs, and icon catalog names. AI is allowed to edit copy, labels, placeholders, option text/descriptions, validation, rules, submit copy, and success messages only.

## Residual Differences

The converted templates use native MegaForm controls inside mock-derived shells. This preserves builder usability and AI editability, but it is not a raw React DOM clone. Small height deltas remain because native inputs, select/date widgets, option controls, and validation wrappers have their own renderer contract.
